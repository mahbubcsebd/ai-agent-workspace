# ai-agent-workspace

This repository contains my custom AI agents, skills, and configuration files for Claude Code, Antigravity, and other AI coding assistants.

## Folder Structure
- `.agents/skills/`: Registered skills containing YAML prompt guidelines.
- `.claude/agents/`: Specialized custom subagents (Frontend, Backend, DevOps, QA, Reviewer).
- `skills-lock.json`: Active skill manifests.
